# Exp - 3 RAILWAY MANAGEMENT SYSTEM

# AIM:
To develop the Railway Reservation System using StarUML.
# SRS (Procedure):

STEP 1:

Railway Reservation System is required to replace the manual process of booking train tickets, managing passenger details, and maintaining reservation records, which is time-consuming and prone to errors.

STEP 2:

Manual reservation processes cause difficulties in checking train availability, managing seat allocations, handling cancellations, and maintaining accurate passenger records.

STEP 3:

Passengers face challenges in searching for trains, checking seat availability, booking tickets, cancelling reservations, and checking PNR status without visiting the railway reservation counter.

STEP 4:

Railway administrators need an automated system to manage train schedules, passenger details, seat availability, ticket bookings, cancellations, and fare information.

STEP 5:

The system should support online ticket booking, secure payment processing, automatic seat allocation, PNR generation, ticket cancellation, refund processing, and report generation.

STEP 6:

It must provide secure role-based access for passengers, administrators, and railway staff, ensuring data integrity, secure transactions, and protection of sensitive passenger information.
